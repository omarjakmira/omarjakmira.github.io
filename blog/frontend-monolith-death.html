The Death of The Frontend Monolith

Micro-frontends are often overkill, but the monolithic React app is also dying. Here is how modern architectures like Islands and RSCs are changing the game.

The Swing of the Pendulum

We went from MPAs (Multi-Page Apps) to SPAs (Single Page Apps) and now we seem to be settling somewhere in the middle with Server Components.

React Server Components (RSC)

RSCs allow us to render components on the server, sending zero JavaScript to the client. This is a game changer for performance, especially for content-heavy sites.

What about complexity?

With power comes complexity. Managing server vs client state, serialization boundaries, and data fetching strategies is harder than ever.
